# AI Virtual Mouse
A Python-based virtual mouse controlled by hand gestures using OpenCV, MediaPipe, and PyAutoGUI.

## Features
- Cursor movement using index finger.
- Left click gesture (Index + Thumb pinch).
- Smooth cursor motion.

## Installation
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python hand_tracking.py`
